Reportar un error

Se abrirá GitHub en tu navegador con un reporte ya prellenado. Max Potion no envía nada por sí sola.

Qué se incluye

  • ✓ Versión, sistema operativo y escritorio
  • ✓ Juego y generación del save abierto
  • ✗ Nombre de entrenador, ID y rutas de tus carpetas
  • ✗ El archivo del save (puedes adjuntarlo tú; contiene datos de tu partida)
Si no se abre el navegador, se copia el enlace al portapapeles.
